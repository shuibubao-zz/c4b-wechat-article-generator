# 粘贴后排版丢失？按这个顺序查

公众号编辑器的问题几乎都出在"HTML 里有它不认识的东西"。
先让机器查，再让人查。

## 第一步：跑合规自检

```bash
python scripts/wechat_check.py 输出.html
```

- `[错误]` = 一定出问题，必须改（div / h1 / script / class / position 等）
- `[提醒]` = 需要人判断（外链图片、正文外链、SVG、超长文）
- 转化时加 `--strict`，有硬错误就直接失败，避免把坏 HTML 带进编辑器

## 第二步：对照现象定位

| 现象 | 最可能的原因 | 修法 |
|------|--------------|------|
| 粘贴后所有样式消失 | 用了 `<style>` 或 `class` | 改成 inline style（转换器已处理，检查源文件里的裸 HTML） |
| 标题不见了 | 用了 `<h1>` | 降级 `<h2>` |
| 大段文字挤在一起 | `<pre>` 被压平 | 用 `<p>` + `<br>` + `&nbsp;` |
| 图片当场裂 / 第二天裂 | 外链或 SVG | 本地 PNG，让转换器转 base64 |
| 表格撑破屏幕 | 列太多 | 拆表，或改成列表；公众号没有横向滚动 |
| 间距忽大忽小 | margin 合并规则不同 | 每个元素显式写 margin |
| 加粗/斜体没了 | `<strong>` 被剥离 | 换成 `<span style="font-weight: bold;">` |
| 目录点不动 | 公众号不支持锚点 | 正常，目录本来就是纯文本索引 |

## 第三步：手机预览必做

公众号编辑器右侧的"预览"只反映排版，不反映真机字体与行距。
发布前用"发送到手机预览"看一遍——这一步能抓出 90% 的行距与图片问题。

## 第四步：仍不对时的最小复现法

把出问题的那一小段单独存成 `t.md`，转换后对比源码与目标 HTML：

```bash
python scripts/convert_to_wechat.py t.md t.html --fragment
```

`--fragment` 只输出正文片段（不含预览外壳），方便直接看标签。

## 关于外链

公众号正文里的外部超链接通常无法跳转。建议：

1. 正文里把链接写成纯文本（`example.com/xxx`）
2. 需要跳转的放「阅读原文」
3. 参考资料统一放文末，用纯文本列出
